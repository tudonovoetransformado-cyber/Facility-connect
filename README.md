# 🏢 Facility Connect

**Aplicativo mobile para gerenciamento de instalações e serviços**

---

## 📱 Sobre o Projeto

Facility Connect é um aplicativo desenvolvido com **Ionic/Capacitor** para gerenciamento de instalações e serviços em tempo real.

### ✨ Características

- 📲 Interface responsiva
- 🔄 Sincronização real-time
- 📊 Dashboard gerencial
- 🔐 Autenticação segura
- 📍 GPS/Localização
- 🎯 Notificações push

---

## 🚀 Quick Start

```bash
# 1. Clone
git clone https://github.com/tudonovoetransformado-cyber/facility-connect.git
cd facility-connect

# 2. Install
npm install
npm install @capacitor/core @capacitor/cli @capacitor/android

# 3. Build
npm run build
npx cap add android
npx cap sync

# 4. Compile APK
cd android
./gradlew assembleDebug
```

**APK gerada em:** `android/app/build/outputs/apk/debug/app-debug.apk`
